# CafePOS — نظام إدارة الكافيه الذكي

نظام نقاط بيع (POS) متكامل لإدارة المقاهي والكافيهات، مبني بـ WPF و .NET 8.

## المميزات

- **نقطة البيع (POS)** — إضافة أصناف، خصم %، اختيار طريقة الدفع، طباعة فواتير حرارية
- **المشتريات** — فواتير مشتريات مع إرفاق ملفات ورقم فاتورة خارجي
- **المرتجعات** — إرجاع أصناف مع طباعة إيصال مرتجع
- **المصروفات** — تسجيل مصروفات (سداد، سلفة، مرتبات عمال)
- **إدارة المنتجات** — إضافة/تعديل/حذف منتجات وفئات
- **إدارة العمال** — بيانات العمال وسحوباتهم
- **التقارير** — تقارير مبيعات، مشتريات، مصروفات، أرباح
- **المناوبات** — فتح وغلق وردية مع محاسبة نقدية
- **الصلاحيات** — 3 أدوار: كاشير، مدير محل، مدير عام
- **الطباعة الحرارية** — دعم عربي كامل (ESC/POS + Raster rendering)
- **النسخ الاحتياطي** — تصدير/استيراد JSON مع مزامنة ذكية
- **الترخيص** — نظام RSA + Hardware ID + 14 يوم تجربة

## التقنيات

| التقنية | الاستخدام |
|---|---|
| .NET 8 WPF | واجهة المستخدم |
| SQLite (Microsoft.Data.Sqlite) | قاعدة البيانات |
| BCrypt.Net-Next | تشفير كلمات المرور |
| ClosedXML | تصدير Excel |
| ESC/POS (winspool.drv) | الطباعة الحرارية |
| System.Management (WMI) | معرف الجهاز (Hardware ID) |

## متطلبات التشغيل

- Windows 10/11 (لوجود winspool.drv و WMI)
- [.NET 8 Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
- طابعة حرارية 80mm (اختياري)

## البدء السريع

### تشغيل التطبيق

```
dotnet run
```

### بناء نسخة قابلة للتوزيع

```
dotnet publish -c Release -o publish/
```

### بيانات الدخول الافتراضية

- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin`
- **الصلاحية:** مدير عام

## هيكلة المشروع

```
CafePOS/
├── App.xaml               # موارد التطبيق (الألوان، الأنماط)
├── App.xaml.cs            # نقطة بدء التشغيل
├── Models/                # كيانات البيانات (16 ملف)
├── ViewModels/            # MVVM ViewModels

├── Services/              # خدمات الأعمال (15 ملف)

├── Helpers/

```

## الترخيص

يتطلب التطبيق ترخيصًا يعتمد على Hardware ID (CPU + Disk + Motherboard). يوفر فترة تجريبية 14 يومًا. لمفاتيح الترخيص، تواصل مع المطور.
